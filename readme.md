# SQL Server / Cloud Database Project

A practical SQL project for managing and analyzing server data.

## Project Objective

The goal of this project is to practice SQL queries used for filtering, sorting, grouping, aggregation, and server data analysis.

## Database

- Database: `cloud_sql`
- Table: `server`

## Table Columns

| Column | Description |
|---|---|
| server_id | Unique server ID |
| server_name | Server name |
| status | Active or inactive |
| cpu | CPU utilization |
| city | Server location |

## SQL Concepts Practiced

- SELECT
- WHERE
- AND / OR
- ORDER BY
- LIMIT
- DISTINCT
- LIKE
- COUNT
- SUM
- AVG
- MIN / MAX
- GROUP BY
- HAVING

## Project Findings

- Total servers: 5
- Active servers: 3
- Inactive servers: 2
- Total CPU: 170
- Average CPU: 34
- Highest CPU: 85
- Mumbai and Pune have average CPU above 50%

## Skills Learned

Practical SQL database operations and server data analysis useful for Cloud Engineering and Cloud Database environments.
